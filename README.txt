شاموتي 2.1 — مجسّم ثلاثي الأبعاد + ربط صوت مباشر بالذكاء الاصطناعي

ما الجديد؟
- زر «محادثة ذكية مباشرة» يستخدم OpenAI Realtime API عبر WebRTC.
- الخادم ينشئ رمز جلسة قصير العمر؛ المفتاح الرئيسي يبقى في الخادم ولا يُرسل للمتصفح.
- الشخصية ثلاثية الأبعاد تتحرك، وتتحرك منطقة الفم أثناء الكلام.
- ما زالت أزرار الردود التجريبية موجودة كخيار احتياطي.

مهم: الاتصال الحقيقي لا يعمل حتى تنشر الخادم وتضع OPENAI_API_KEY في إعدادات Environment. قد تكون هناك تكلفة استخدام API حسب حساب OpenAI وإعداداته.

طريقة النشر المقترحة (Render):
1. ارفع جميع محتويات هذا المجلد (بما فيها مجلد public) إلى مستودع GitHub جديد/خاص، ولا ترفع ملف .env أو مفتاحاً حقيقياً.
2. في Render اختر New > Web Service واربط المستودع.
3. Build Command: npm install
4. Start Command: npm start
5. في Environment أضف OPENAI_API_KEY واجعل قيمته مفتاح مشروع OpenAI الخاص بك. لا تضع المفتاح داخل index.html ولا ترسله في المحادثة.
6. انشر الخدمة وافتح رابط HTTPS الذي يعطيك إياه Render. افتح الرابط من Chrome، اسمح بالميكروفون، ثم اضغط «محادثة ذكية مباشرة».
7. اختبر الرابط /health؛ يجب أن يرجع JSON فيه ok:true.

إعداد المفتاح:
- أكمل نافذة إعداد مفتاح OpenAI التي فُتحت في ChatGPT، ثم انسخ/نزّل المفتاح بالطريقة الآمنة التي تعرضها لك الواجهة.
- إذا لم تحفظ المفتاح، أنشئ مفتاح مشروع من OpenAI Platform. لا تلصقه في هذه المحادثة أو في ملف frontend.
- استخدام API قد يتطلب تفعيل الفوترة/رصيداً منفصلاً عن اشتراك ChatGPT.

التشغيل محلياً:
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ npm install.
3. ضع المفتاح في متغير بيئة OPENAI_API_KEY (أو ملف .env مع أداة تحميل مناسبة؛ الخادم الحالي لا يقرأ .env تلقائياً).
4. نفّذ npm start ثم افتح http://localhost:3000.
5. ميكروفون المتصفح يعمل عادة على HTTPS أو localhost فقط.

ملاحظات تقنية:
- يعتمد المجسّم على Three.js من CDN، لذلك يلزم الإنترنت لتحميله.
- الصوت المباشر يستخدم OpenAI Realtime عبر WebRTC، بينما المفتاح الرئيسي يبقى على الخادم ويصدر الخادم رمز جلسة مؤقتاً.
- لا تضع مفتاح API في GitHub أو داخل index.html. إذا انكشف المفتاح، ألغِه فوراً وأنشئ غيره.
- هذه نسخة PWA/ويب وليست APK Android أصلياً. لم يتم نشرها تلقائياً على حساباتك أو تفعيل مفتاح API نيابة عنك.
